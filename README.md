# MOTOR-DE-SINAL-DELTA
Aplicação pessoal DELTA SIGNAL ENGINE em Flutter para Android e iOS. Análise estatística de futebol com sinais T01–T05, resultados reais, calibração, backtest cronológico, importação CSV/JSON e base de dados local SQLite. Exclui jogos SRL/realidade simulada. Foco na validação estatística e no controlo de risco.
